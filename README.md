# Emaresa Clima Demo

Demo funcional del Dashboard de Clima Organizacional para Grupo Emaresa.

## Stack

- React 18
- Vite 5
- TypeScript
- Tailwind CSS
- React Router DOM con HashRouter

## Setup local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

El deploy de GitHub Pages sirve el sitio desde `/emaresa-clima-demo/`, configurado en `vite.config.ts`.
